Chat continuity
Recent turns stay verbatim. Older turns become compact factual memory when context fills up. Editing, swiping or rolling back past messages invalidates the affected summary. Memory belongs to the selected chat.
Select a character and chat first.
Generate a reply to inspect its context.
Hardware context is the total space for the character, history, instructions and reply. Longer replies leave less space for history. Increasing context can use more RAM / VRAM.


Local image generation
Portraits, scenes and illustrations inside your tavern. Images use a separately managed KoboldCpp worker, so switching image models keeps your text model running. Stop the image worker to free its RAM / VRAM.
Custom model download

Recommended: DreamShaper 8 (2.13 GB), a practical general-purpose SD 1.5 model. Optional: DreamShaper XL Turbo (6.94 GB), more detail and higher memory usage. Model licence terms are linked in each card.
