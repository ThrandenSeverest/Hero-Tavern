Текстовые файлы · безопасное редактирование

Добавьте файл с компьютера — создаётся отдельная копия в рабочей папке Hero Tavern. Ассистент не получает доступ к произвольным путям на диске и не перезаписывает исходный файл. Сначала предпросмотр, затем кнопка применения, а оригинальную версию можно восстановить.

Посмотреть отличия

Максимальный импорт: 300 КБ. Автоматическая переработка за один ответ рассчитана на тексты до 12 500 символов; для больших файлов потребуется обработка фрагментами. Скачивание обратно осуществляется через браузер.

Modern ComfyUI workflows · FLUX / Z-Image / Qwen
For RTX 5070 12 GB, try a compatible SDXL checkpoint first. For newer model architectures, consider FLUX.2 Klein 4B official guide (fast generation and reference editing) and Z-Image Turbo official model package (fast detailed generations). Both use multi-component workflows. Import a compatible ComfyUI API JSON; do not rename diffusion weights as an SDXL checkpoint. Downloads are not automatic.


For non-SDXL model families, import an official ComfyUI API workflow JSON. These models often need separate diffusion weights, text encoders and VAE; a single checkpoint menu cannot run them correctly.









Only import workflows from authors you trust. ComfyUI custom nodes execute in the external local ComfyUI process. No model or generated-image files are deleted by this importer.
Templates use literal placeholders in API node inputs: {{prompt}}, {{negative}}, {{seed}}, {{steps}}, {{width}}, {{height}}, {{guidance}}, {{source}}, {{mask}}. When none are present, the imported workflow runs with its original fixed values. Uploaded graphs are local and are never automatically executed on import.
