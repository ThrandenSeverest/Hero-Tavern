Modern ComfyUI workflows · FLUX / Z-Image / Qwen
For RTX 5070 12 GB, try a compatible SDXL checkpoint first. For newer model architectures, consider FLUX.2 Klein 4B official guide (fast generation and reference editing) and Z-Image Turbo official model package (fast detailed generations). Both use multi-component workflows. Import a compatible ComfyUI API JSON; do not rename diffusion weights as an SDXL checkpoint. Downloads are not automatic.


For non-SDXL model families, import an official ComfyUI API workflow JSON. These models often need separate diffusion weights, text encoders and VAE; a single checkpoint menu cannot run them correctly.









Only import workflows from authors you trust. ComfyUI custom nodes execute in the external local ComfyUI process. No model or generated-image files are deleted by this importer.
Templates use literal placeholders in API node inputs: {{prompt}}, {{negative}}, {{seed}}, {{steps}}, {{width}}, {{height}}, {{guidance}}, {{source}}, {{mask}}. When none are present, the imported workflow runs with its original fixed values. Uploaded graphs are local and are never automatically executed on import.

Model Testing · reproducible multimodal tests
Uses fixed built-in prompts, the selected local models, and real generated outputs. Every result is saved under Diagnostics/model-tests.json. It reports failures, timing, actual prompts and settings, visual similarity warnings, and preserves all generated images.


Tests have strict time limits and cancellable ComfyUI jobs. Heavy Qwen reference editing is opt-in on 12 GB cards. The standard visual tests use the same fixed red-teapot and green-frog prompts for each image model. A reference is explicit for image-to-image; it is never silently inherited by text-to-image.
Select an image model, then run an individual test or the complete suite.
Fixed test prompts and criteria
Text → Text: Exact reply BLUE LANTERN, no commentary. Text → Image: Red teapot on white table, then green frog in blue scene. Image → Image: Recolor reference object blue while keeping composition. Image → Text: Describe the selected output's visible content in two factual sentences.
Automated image checks detect duplicate bytes, abnormally flat outputs and suspiciously similar spatial color. A passing automatic check does not establish artistic quality; visually inspect the pictures.


Diagnostic tests
